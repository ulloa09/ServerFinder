Spotlight doesn't index network drives. ServerFinder keeps its own index of your Windows or NAS shares, on your Mac, and searches it as you type, by file name or by the words inside documents.

    Inside files

    What it can read

    Documents are read in the background after each scan. Later scans only read what changed.

    FormatExtensionsHow it's read
    PDF.pdfThe text layer with PDFKit. Pages with no text go to text recognition, up to 100 pages.
    Word.docx.docmacOS's own document readers.
    PowerPoint.pptxThe text runs of every slide, straight from the file's XML.
    Excel.xlsxShared and inline cell strings. Numbers and formulas are skipped.
    Excel 97–2003.xlsA built-in reader for the Compound File and BIFF8 formats. Web pages exported as .xls are read too.
    Pictures.jpg.png.heic.tiffApple's Vision text recognition, Spanish and English, every page of a multi-page TIFF.
    Text.txt.csv.rtf.xmlUTF-8, UTF-16 or Windows-1252, detected per file.

    Files named like *contraseña* or *password* are still found by name, but their contents are never read.

    Engineering

    Measured on a real file server

    Developed against a production Windows Server 2022 share over office Wi-Fi. Native Swift, no third-party dependencies, 130 automated tests.

    Search runs on two SQLite full-text indexes stored in one file on your Mac. File paths use a trigram index, so any fragment of a name matches. Document text uses word tokens with accents removed, which keeps the index small and makes cotiz find "cotización".

    -- names: any fragment of the path matches
CREATE VIRTUAL TABLE entries USING fts5(
    search_path, name, share, relative_path, size, modified, …
    tokenize = 'trigram'
);

-- document text: words, accents removed
CREATE VIRTUAL TABLE contents USING fts5(
    text,
    tokenize = 'unicode61 remove_diacritics 2'
);
    Privacy

    Read-only, and it stays on your Mac

    Built for shared company folders, where one wrong move costs more than a slow search.

    • Never writes to the server. No file is changed, moved or deleted.
    • No account, no analytics, no network requests beyond the server connection macOS already made.
    • One local file holds the index. Delete it, or erase all stored document text from Settings.
    • Light on battery. Indexing runs at low priority, and text recognition waits out Low Power Mode and a hot Mac.
    Install

    Running in two minutes

    Requires macOS 15 Sequoia or later and a shared folder you connect to in Finder over SMB.

    1. Download ServerFinder.dmg, open it and drag ServerFinder into Applications.
    2. Open it once. macOS says it can't verify the app; click Done.
    3. System Settings → Privacy & Security, scroll to ServerFinder and click Open Anyway.
    4. Add your server folders in the window that opens, then press ⌥ Space and type.

    Why step 3? The app isn't signed with a paid Apple developer certificate, so macOS asks once. Every line of code is on GitHub, and each release lists the checksum of the download.
